# Export Tie-In Concept Agent

Screens a new export or tie-in line between two facilities end to end: ranked landing points, seabed profile,
hydraulics, wall thickness and size, and conceptual P&ID sketches of both ends.

## Capabilities

- Rank landing points on neighbouring hosts with an explainable score
- Profile, pressure drop, thermal decay, wall thickness and size per rate case
- P&ID sketches (SVG) of source and landing ends with a completeness check
- List open options and unassessed items as questions for facility owners

Built from the Martin Linge A to Oseberg A oil export screening. Screening only; human review required.
