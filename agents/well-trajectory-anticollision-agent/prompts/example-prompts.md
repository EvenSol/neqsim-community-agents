# Example Prompts

## Sidetrack and Anti-Collision

```text
Use the Well Trajectory and Anti-Collision Agent to plan a sidetrack from a closed template bore to a
public synthetic target and check it against the offset wells with the ISCWSA separation factor. Report
the governing offset, the parent exit depth and the assumptions.
```

## Target Pull-Back

```text
Use the Well Trajectory and Anti-Collision Agent to find how far a target must move towards the slot so
that no offset well is below separation factor 1.5. Show the sweep and flag the subsurface consequence.
```

## Slot Check

```text
Use the Well Trajectory and Anti-Collision Agent to check whether slot 02 on a public synthetic template
is free, occupied or recoverable by sidetrack, before planning a new well from it.
```
