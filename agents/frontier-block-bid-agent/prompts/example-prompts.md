# Example Prompts

## Break-even share

```text
Use the Frontier Block Bid Agent to find the break-even State profit-oil share for a
public synthetic pre-salt block at 70% working interest, with a 30% chance of
discovery. State assumptions and human review requirements.
```

## Near-field versus stand-alone

```text
Use the Frontier Block Bid Agent to compare a tie-back to a nearby FPSO with a
stand-alone development for a public synthetic block and report the synergy value
and the sensitivities that flip the answer.
```

## Brazilian round with the Annex XX table

```text
Use the Frontier Block Bid Agent for a Santos pre-salt block: apply the ANP Annex XX
profit-oil table at 28,000 bbl/d per producer, report EMV with and without the
development option, break-even chance of discovery, the P50 volume for EMV = 0, and
the host gas-handling check. List every UNKNOWN tariff.
```
